# 数据依赖与排期（RE 视角）

> 2026-11-05。列出 RE 当前仍然阻塞的对账/生产依赖，按优先级给出验收标准与负责方。
> 数据事实以 `svquant-data` 发布为准；本文件只记录 RE 的消费方式与降级行为。

## P0：分钟线 2016–2024（阻塞 5 个策略，影响全部盘中成交）

- 现状：`ifind/high_frequency/1min` 只有 **2025-01-10 ~ 2026-09-09（442 个交易日）**；2016–2024 免费源无深历史，iFinD 当期快照也没有。
- RE 行为：`timed_execution` 的 09:31/10:05/14:45 盘中时点在没有分钟数据的日期回退为「日线开盘/收盘近似」，`assumptions.intraday_price` 会标注；所有报告都按降级口径登记。
- 影响：价值类 v3 的补单窗口与 10:00 止损/破板卖出触发时点不同，是当前选股差异的第二大来源（第一是已修复的财务口径）。
- 需求：2016-01-01 起全市场 1m（或 5m，体积约 1/5）。验收：随机 20 个交易日的 09:31/10:05/14:45 三点与聚宽回测成交价一致率 ≥ 99%，缺行率 < 0.1%。
- 负责方：数据侧（付费 iFinD 分钟导出或等价源）；RE 侧已具备 `MinuteStore`，数据到位即可用，无需改代码。

- 需求：按公告日保留「原值 + 修订值」两版，或至少提供修订事件表。验收：随机 50 个 2016–2020 财报期的扣非/归母与聚宽同期一致率 ≥ 99%。
