## 五、口径说明

- 分层：L0 参数与日历 → L1 选股集合 → L2 成交 → L3 持仓 → L4 净值 → L5 指标。
- 持仓重合：按全区间曾持有过的标的去重统计。
- 终值：以各自初始资金为基准的期末权益。
- 报告文件在本地 `output/joinquant-parity/`，金标同样只在本地使用，不入库。
