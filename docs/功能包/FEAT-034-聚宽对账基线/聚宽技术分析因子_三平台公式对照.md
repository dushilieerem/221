# 聚宽技术分析指标因子：通达信 / 东方财富 / 同花顺公式对照

> 整理日期：2026-09-09；范围：聚宽 technicalanalysis 页面当前可见的 98 个因子。
>
> 本文把“对应公式”分成两层：平台备注中的“同公式/算法不同/无同名指标”，以及可放入三家电脑版公式编辑器的自编公式。无同名指标并不表示不能自编，而是表示没有可直接调用的同名内置指标。

## 1. 结论与使用边界

- 聚宽页面明确说明：技术指标因子基于通达信、东方财富、同花顺等公式整理；由于复权数据、算法和回溯数据量可能不同，数值不保证与软件逐点相等。
- 下方公式默认使用 CLOSE/HIGH/LOW/OPEN/VOL/AMOUNT 等常见字段；通达信常见别名还包括 C/H/L/O/V/AMO。东方财富、同花顺请优先用编辑器的“插入函数/字段”替换，特别是 INDEX*、CAPITAL、HSL、FINANCE(*)、VOLINSTK。
- 冒号表示输出线，:= 表示中间变量，分号表示语句结束。N/M/N1... 是参数占位符；复制到软件后在参数设置中声明，或直接改成常数。
- 代码块是“JoinQuant 口径的可迁移公式”。对于平台备注标成“无同名指标”的软件，代码应作为自编指标使用；对于“算法不同/参数不同”，代码只代表 JoinQuant 口径，不冒充该平台当前内置实现。
- MTM 当前页面默认周期为 14；本机旧版 jqdatasdk 文档中曾出现默认 12，这是版本差异，不应混用。

## 4. 逐因子公式

> 每个小节都给出 API 签名、三平台对照和公式。公式变量名可以改成中文显示名；不要把显示名差异误判成算法差异。

### 超买超卖型

#### 1. ACCER — 幅度涨速

JoinQuant API：`ACCER(security_list, check_date, N = 8, unit = '1d', include_now = True, fq_ref_date = None)`

平台对照：通达信：`同公式`；东方财富：`无同名指标`；同花顺：`无同名指标`。

JoinQuant 备注：计算方式与通达信相同，东方财富和同花顺没有该指标

公式（JoinQuant/通达信口径）：

```text
ACCER:SLOPE(CLOSE,N)/CLOSE;
```

#### 2. ADTM — 动态买卖气指标

JoinQuant API：`ADTM(security_list, check_date, N = 23, M = 8, unit = '1d', include_now = True, fq_ref_date = None)`

平台对照：通达信：`同公式`；东方财富：`同公式`；同花顺：`同公式`。

JoinQuant 备注：计算方式与通达信，同花顺和东方财富相同

公式（JoinQuant/通达信口径）：

```text
DTM:=IF(OPEN<=REF(OPEN,1),0,MAX((HIGH-OPEN),(OPEN-REF(OPEN,1))));
DBM:=IF(OPEN>=REF(OPEN,1),0,MAX((OPEN-LOW),(OPEN-REF(OPEN,1))));
STM:=SUM(DTM,N);
SBM:=SUM(DBM,N);
ADTM:IF(STM>SBM,(STM-SBM)/STM,IF(STM=SBM,0,(STM-SBM)/SBM));
MAADTM:MA(ADTM,M);
```

迁移提示：若三家软件的字段或函数名不同，请用目标软件的函数插入器替换字段后再保存测试。
