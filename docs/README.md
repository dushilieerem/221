## 维护规则

1. 当前版只写语义目录，不再使用目录编号；`FEAT-*`、`ADR-*` 等文档 ID 保留。
2. 长期结构写 `模块设计/`，一次交付写 `功能包/`，两者不混放。
3. 旧版移动到 `归档/YYYY-MM-主题/`，保留原结构，不直接删除。
4. 移动文档时同步修复相对链接，并检查全库本地链接。
5. 跨仓库引用写仓库路径或 URL，不写本机盘符路径。
