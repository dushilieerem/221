# ResearchEngine 数据清单

本文档记录当前已发布、服务可读取的数据资产，供研究员确认可用字段、覆盖区间和访问入口。

行情部分是对 `data.dir` 指向的 MarketData release 的**快照记录**：文件 schema 与字段来源仍属于数据发布契约，由发布方维护，本仓库不复刻其定义；清单中的版本、文件、行数和 SHA-256 以该目录的 `data_manifest.yaml` 和 `quality_report.json` 为准。数据版本切换后需要同步更新本页。

当前记录对应数据版本：`ifind-sync-20261101`（2026-11-01 核对；以 `views/current/manifest.json` 与 `data_contract.yaml` 为准）。

> 数据采集、规范化、PIT、发布与质量已交接给 `svquant-data`。本页只记录 ResearchEngine 的消费入口与字段用途；最新字段/覆盖/单位以 `svquant-data/docs/data_contract.yaml` 和发布物内的 `data_contract.yaml` 为准。

`date_sequence` 的原始列名沿用 iFinD 超级命令命名；服务对外只暴露去掉 `ths_` 前缀和 `_stock` 后缀后的逻辑字段名：

| `ths_current_mv_stock` | `current_mv` | 总市值 |
| `ths_dividend_yield_ttm_stock` | `dividend_yield_ttm` | 滚动股息率 |
| `ths_listed_status_stock` | `listed_status` | 上市生命周期状态 |

## 9. 使用注意事项

- **复权口径**：因子使用后复权 OHLC，收益使用后复权 `close`；`unadjusted_price` 只用于行情展示接口，不参与因子计算。
- **缺失值**：缺失保持为缺失，不要用最新静态值回填历史，也不要把缺失自动当成零、停牌或退市。
- **状态字段**：`up_and_down_status` 为 NA 只说明该日无可用记录，不等价于退市；当前 release 没有可靠的独立停牌字段，停牌过滤按缺失字段跳过处理。
- **退市判定**：只用 `listed_status`，不要用 `up_and_down_status`。取值 `终止上市`、`退市整理`、`暂停上市` 即不可投资；`up_and_down_status` 在退市相关单元格里约 97% 是 NA，无法识别退市。因子与策略回测会**强制**按 `listed_status` 白名单（`在市`/`ST`/`*ST`）剔除不可投资标的，无开关可关，详见[因子回测接口文档](../功能包/FEAT-002-研究引擎/06-研究接口文档/backtest-factor.md)。
- **退市后行情被前值填充**：`market_data_hfq.parquet` 的 OHLC 在标的终止上市后**不再置空**，而是冻结在最后成交价（只有 `volume`/`amount` 变成 NA）。全库约有 68.9 万个「close 有值但 volume 为空」的冻结单元格，占非空 close 的 5.8%。直接用价格面板做横截面（尤其低波动/低 beta 类）会把冻结的退市股排在前面，必须依赖上述退市剔除。
- **已知残留**：白名单只认上市状态，无法识别「长期停牌但仍在市」的标的（其价格同样被冻结）。这类单元格约占白名单内允许样本的 1.6%，其中处于连续 60 日以上停牌的约 0.44%。需要更严口径时另行叠加停牌过滤。
- **数据版本**：回测结果应记录使用的 `release_id` 与 `data_version`。当前配置未锁定 `expected_version`，服务会跟随行情发布自动更新（约 1~2 分钟生效）。
- **分钟线**：已发布但未接入，见第 5 节。
- **指数范围**：只有沪深300和中证500，见第 4 节。
