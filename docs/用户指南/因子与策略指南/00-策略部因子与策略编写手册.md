# 策略部因子与策略编写手册

> 适用对象：策略部研究员、策略开发同事
> 使用目的：把研究想法整理成可复现的因子实验和策略验证。本文以研究问题、数据口径和结果判断为主；ResearchEngine 的代码接口见[因子实现速查](01-factor-writing.md)，策略代码细节见[向量化策略规范](02-vectorized-strategy-writing.md)和[事件策略规范](03-event-strategy-writing.md)。

## 1. 先选研究对象

| 研究问题 | 先写什么 | 产出 | 适用情况 |
|---|---|---|---|
| 哪些股票未来相对更强？ | 因子 | 每个交易日、每只股票一个可比较的分数 | 验证选股信号和预测能力 |
| 按分数如何选股、配权和调仓？ | 向量化策略 | 日期 × 股票的目标权重 | 规则主要是打分、筛选、组合和固定节奏调仓 |
| 订单何时提交、持仓如何变化？ | 事件策略 | 按时间运行的订单和持仓行为 | 需要止损、状态、T+1、涨跌停或停牌规则 |

通常先单独验证因子，再组合成策略。因子检验回答“排序有没有信息”；策略回测回答“按具体选股、权重和交易规则实施后表现如何”。两者的收益不能互相替代。

## 2. 每项研究先写清楚假设

开始写代码前，先把下面几项写进研究记录。公式和代码应能对应到同一个假设。

| 项目 | 要写清楚的内容 |
|---|---|
| 研究假设 | 哪种信息或行为会带来什么收益差异？预期关系为何成立？ |
| 因子定义 | 数学公式、单位、参数、缺失值和异常值处理方式。 |
| 方向 | 高分是否代表预期收益更高；若原始公式方向相反，明确是否取负。 |
| 数据可得时点 | 信号在什么时候形成；输入字段在当时是否已公开、可交易者是否可见。 |
| 股票池 | 市场范围、成分股口径、上市状态和过滤规则。 |
| 预测周期 | 信号预测未来几日或几个月；与调仓频率分别记录。 |
| 对照方案 | 基准因子、基准指数、简单策略或不加该信号的原组合。 |
| 预设判断标准 | 何种稳定性和经济意义足以继续；何种结果应停止或降级。 |

**预测周期不等于调仓频率。** 例如，20 日收益因子可以每 5 日调仓，也可以每 20 日调仓；这两种实验回答不同问题。应在看结果前确定要检验的持有周期和调仓方式。

## 3. 因子设计与数据纪律

### 3.1 一个因子表达一个主要观点

- 先构造单一、可解释的信号，再研究与其他因子的组合。组合因子要写出各分量、方向、权重和组合理由。
- 定义高低值含义。推荐统一为“分数越高，预期收益越高”，避免同一份报告里动量、估值和风险因子方向不一致。
- 区分时间序列和横截面问题。`过去 20 日收益`描述单只股票自身变化；“当日股票之间的动量排序”才是横截面选股信号。
- 优先让不同股票之间可比。绝对价格通常不可直接横向比较；可考虑收益率、比例、标准化值或横截面排名，并说明采用理由。
- 参数应有经济含义。不要仅因某个窗口在全样本表现最好，就把它当作稳定规律。

### 3.2 对齐信息出现的时间

- 计算日期为 `t` 的信号时，只能用 `t` 时点已经可获得的信息；不能用 `shift(-1)` 或任何未来行情填补当前信号。
- 使用收盘价计算的信号，策略执行时要考虑该收盘价何时可知、下一次可成交的价格是什么。不要默认能在形成信号的同一收盘价成交。
- 财报期末日不等于公告日。使用财务字段前，先确认历史数据是否按公告时点重建；若无法确认，需在报告中标明点时限制，不能把报告期末值直接当作当时可见值。
- 核对股票池的历史成分口径。若回测采用固定或当前成分，需明确写出；这类结果不能直接解释为完整历史指数成分下的可投资收益。
- 不用最新行业、ST、上市状态或静态估值回填历史。缺少历史字段时，缩小研究范围或将限制写进结论。

### 3.3 缺失值、异常值和预处理

- 先报告有效覆盖率及缺失集中在哪些股票、年份和行业。缺失值不应无条件填成 0；只有 0 确实代表业务含义时才填 0。
- 去极值、标准化、排名、中性化都是研究设定的一部分。记录方法、作用顺序和暴露口径，并在因子间比较时保持一致。
- 保留原始信号作为基线，再单独比较处理后的版本。不要在因子公式和回测选项里重复做同一项处理。
- 负值、零值、停牌和极端值需按公式含义处理。分母可能为零或为负时，先确定经济定义，再决定返回缺失值、截断还是另设分支。

## 4. 研究流程

1. **固定规格**：冻结假设、股票池、因子方向、评价周期、基准和主要参数。
2. **核对数据**：确认字段可用、单位一致、发布日期正确，并检查覆盖率和历史股票池。
3. **跑单因子基线**：先使用简单公式和默认预处理，留存原始结果。
4. **读预测证据**：观察 IC/RankIC、分层收益、分组单调性、覆盖率和稳定性，不只看年化收益或夏普。
5. **做稳健性检查**：按时期、行业、市值、市场状态和相邻参数重复检验；对照基准与简单替代方案。
6. **验证组合实现**：将通过初筛的信号放进明确的策略规则，检查换手、交易成本、容量、回撤和可成交性。
7. **留出样本复核**：开发期用于形成假设，验证期用于筛选，留出期用于最终确认；留出结果不用于继续调参。
8. **写结论**：记录支持、反对或无法判断的证据，以及适用范围和未解决的数据限制。

多次试验过的公式、参数和股票池也属于研究过程。应留档失败版本和调整理由，避免只报告最终胜出的结果。

## 5. 如何读因子结果

| 证据 | 看什么 | 解读时注意 |
|---|---|---|
| 覆盖率 | 每日有效股票数、年份分布、缺失原因 | 覆盖突然下降可能让不同年份的结果不可比。 |
| IC | 每日因子值与未来收益的截面 Pearson 相关及其时间序列 | 看均值、波动和正负时期；少量极端日期不应支撑结论。 |
| RankIC | 因子排名与未来收益排名的相关性 | 对单调关系更直接，也应检查稳定性和有效样本数。 |
| 分层收益 | 高分组到低分组是否大致单调，最高与最低组差距如何 | 单看最高组收益可能只是市场或风格暴露。 |
| 分行业/市值结果 | 信号在哪些行业、规模段有效 | 若效果只来自一个窄子集，应限制结论范围。 |
| 换手与组合收益 | 调仓变化、成本假设、回撤和容量 | 因子分层是研究证据；最终策略仍需按实际交易约束验证。 |

ResearchEngine 当前因子分析的 IC 标签默认是因子 `t` 对应收盘到下一交易日收盘的收益；`rebalance_days` 控制分层组合的调仓间隔，不会改变 IC 标签的预测天数。研究更长持有周期时，应使用相应的策略回测或其他明确的远期收益检验，不能把默认 IC 当成长周期预测结论。详见[因子回测接口说明](../../功能包/FEAT-002-研究引擎/06-研究接口文档/backtest-factor.md)。

因子分组中 `Q1` 是因子值最高组，`QN` 是最低组。若预期高分代表更高收益，通常希望高低组差异方向合理，并在多个时期、相邻分组和不同样本下保持可解释；不要求每个单独年份都盈利，但不能只挑选有利年份呈报。

## 6. 稳健性和停止条件

每个项目根据业务预先设定判断线；不设通用的 IC、收益或夏普及格线。至少完成以下检查：

- **时间稳定性**：分年度或滚动窗口检查方向与贡献，区分结构性失效和少数极端年份。
- **股票池稳健性**：在研究问题允许的相邻股票池或市场范围复核，并统一成分股口径。
- **风格暴露**：检查行业、市值、流动性等暴露；比较控制暴露前后的结果。
- **参数敏感度**：测试少量有事前理由的相邻参数，观察结果是否仅在单一点有效。
- **交易可行性**：记录换手、冲击成本估计、涨跌停、停牌和容量限制。
- **样本外确认**：冻结公式后再看留出时期；留出期若不支持假设，不应继续用它调到通过。

出现以下情况时，应停止、重做数据或明确降级结论：

- 方向依赖未来数据、幸存者样本或未经确认的财报时点；
- 有效覆盖率太低，或结果由少数股票、日期、行业贡献；
- 参数轻微变化或换一个相邻时期，结论就反转；
- 扣除合理的换手成本或考虑实际成交限制后，经济意义消失；
- 试验数量很多但只保留最好的一组结果，无法说明样本外证据。

## 7. 从因子走向策略

- 先用单因子建立基准，再加入互补信号；若两个因子表达同一风险或风格，不因相关系数低就默认它们互补。
- 在策略报告中冻结选股规则、权重、调仓日、持有期、退出规则和基准。只比较收益还不够，也要看换手、回撤、集中度和成本后表现。
- 纯粹输出目标权重时使用[向量化策略](02-vectorized-strategy-writing.md)；需要订单时点、持仓状态或 A 股交易规则时使用[事件策略](03-event-strategy-writing.md)。
- 事件策略以回测引擎实际支持的成交规则为准。若交易价格、交易频率或可交易字段不符合策略假设，应标为研究模拟，不能视为实盘可复制结果。
- 研究结论要区分“信号有效”“组合构造有效”和“交易后仍有效”，不要把其中一项替代另外两项。

## 8. ResearchEngine 上机速查

本节只给出把公式交给当前平台计算的最小约定。函数需返回“日期 × 股票”的因子值表；计算尽量使用 Pandas 宽表运算，不逐只股票、逐日循环。更完整的接口约束见[因子实现速查](01-factor-writing.md)。

```python
def momentum_20d(self):
    """过去 20 个交易日收益率；值越大，动量越强。"""
    return self.close.pct_change(20)

def low_volatility_20d(self):
    """过去 20 日收益波动率取负；值越大，历史波动越低。"""
    return -self.close.pct_change().rolling(20).std()
```

当前常用面板字段如下。实际可用字段取决于本次行情数据版本；编写前检查 `self.fields`，缺字段时不要用最新静态值补历史。

| 类别 | 当前字段 |
|---|---|
| 价格 | `open`、`high`、`low`、`close` |
| 成交 | `volume`、`amount`、`turnover` |
| 市值 | `current_mv` |
| 估值 | `dividend_yield_ttm`、`pe_ttm`、`pb_mrq`、`pcf_operating_cash_flow_ttm` |
| 状态/行业 | `listed_status`、`the_sw_industry_code`、`up_and_down_status` |
| 指数行情 | `self.csi300.close`、`self.csi500.close`、`self.csi1000.close`、`self.sse50.close` |

股票字段以 `self.close` 这类属性访问；其他已装载字段可用 `self["字段名"]` 访问。滚动窗口前的缺失值通常保留，不要用未来值填补。因子函数名称、提交和轮询方式见[因子实现速查](01-factor-writing.md)及[回测接口说明](../../功能包/FEAT-002-研究引擎/06-研究接口文档/backtest-factor.md)。
