# ResearchEngine 系统文档

本目录按软件项目标准文档结构维护 ResearchEngine 的当前系统基线。文档描述本仓库中已实现或明确受限的能力；功能提案、迭代过程、历史验证和技术决策仍保留在原有文档目录。

## 文档目录

| 类别 | 文档 | 说明 |
|---|---|---|
| 需求 | [PRD](需求文档/PRD.md) | 用户、范围、业务规则和验收基线 |
| 架构 | [系统架构](架构文档/系统架构.md) | 边界、模块、数据流、运行和部署约束 |
| 模块详细设计 | [模块设计](模块详细设计/研究引擎/模块设计.md)、[类设计](模块详细设计/研究引擎/类设计.md)、[流程设计](模块详细设计/研究引擎/流程设计.md) | ResearchEngine 内部职责、核心对象和运行时序 |
| 数据库 | [数据库设计](数据库设计/数据库设计.md)、[数据清单](数据库设计/数据清单.md) | 因子资产库、批量回测库、缓存和外部行情数据；数据清单记录当前 release 的可用字段与覆盖区间 |
| API | [API 设计](API设计/API设计.md) | 路由索引和各接口的详细契约入口 |

| 部署 | [部署文档](部署文档/部署文档.md) | 环境、配置、启动、健康检查和故障排查 |

## 文档职责与维护

- 本目录记录系统级当前事实；接口字段、数据库 schema 和运行边界以代码与契约测试为准，变更时应同步更新对应文档。
- [`../03-功能文档/`](../03-功能文档/) 保留按 FEAT 拆分的需求、设计和验证材料；具体功能规则仍以对应 Feature 文档为准。
- [`../02-架构文档/researchengine_architecture.md`](../02-架构文档/researchengine_architecture.md) 保留早期架构展开稿，尚有未与当前代码校准的内容；当前基线以本目录的[系统架构](架构文档/系统架构.md)为准。
- [`../05-技术决策/`](../05-技术决策/) 保存长期技术选择；已接受决策应同步到系统架构和相关模块设计。
- FEAT-002 下的旧架构、模块、类和运行流程草稿保留作历史追溯，当前基线见本目录对应文档。

项目级产品背景和跨仓库文档入口见仓库根目录 [`README.md`](../../README.md) 及同级项目文档中心。
