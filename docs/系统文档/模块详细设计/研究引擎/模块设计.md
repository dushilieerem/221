# ResearchEngine 模块设计

## 1. 模块信息

- 模块名称：ResearchEngine 研究服务
- 负责人：仓库未登记
- 所属系统：SVQuant 研究计算服务
- 文档版本：1.0
- 当前实现入口：`app/main.py`

---

## 2. 模块职责

本模块负责：

1. 接收并校验研究 HTTP 请求，转换为服务可处理的规格。
2. 读取经清单校验的外部行情和随仓库发布的因子/策略资产。
3. 编排因子、策略、组合、回测、指标及批量研究任务。
4. 管理当前进程内的实验并发、任务状态和批次状态。
5. 返回结构化 API 结果，并按配置使用批量 SQLite、字段缓存和结果存储。

本模块不负责用户身份与权限、资产 CRUD、MarketData 生产发布、Web UI、实盘交易或不受信任代码的安全隔离。

| HTTP 请求 | WebApp、CLI、SDK 等客户端 | JSON，经 `app.schemas` 校验 |

| 策略资产 | 配置指定的索引和策略目录 | YAML、Python |

## 7. 核心逻辑

### 应用启动

1. `app.main` 读取并解析根目录 `config.yaml`。
2. 对比 MarketData Manifest、期望版本和可选 SHA-256。
3. 装载只读数据 Provider，不预先将全部字段读入内存。
4. 启动 `ExperimentManager` 和批量任务注册表。
5. 关闭时先等待批量协调任务，再关闭 Manager 和数据引擎。

### 因子回测

1. 校验请求并规范化为 `FactorBacktestSpec`。
2. 构造 `FactorBacktestExperiment`，提交到 Manager。
3. `BacktestEngine` 依次请求行情、计算因子、构造组合和计算指标。
4. 汇总数据发布、规格哈希、执行版本、诊断和结果。
5. HTTP 因子端点返回任务标识；调用方轮询读取最终结果。

### 策略回测

1. 校验策略输入及 execution mode 所需能力。
2. 提交策略任务到 Manager。
3. 由向量化或事件执行器生成结果。
4. HTTP handler 等待 Manager 任务完成后返回响应。

### 批量回测

1. 校验批量参数，创建或复用批次任务。
2. 协调器读取因子目录并运行单因子实验。
3. 记录批次与单因子状态、汇总指标和预测指标到独立 SQLite。
4. 通过任务、批次、因子列表和历史接口查询。

### 行情状态字段

`listed_status` 和 `up_and_down_status` 是不同语义的字段。涨跌停/停牌状态字段为 NA 时，数据层不会据此推断退市；退市判定应使用上市状态或数据源提供的退市信息。字段缺失还可能由上市前无记录或字段覆盖范围不同造成。

## 9. 数据依赖

读取：

- `data.dir` 下由 `data_manifest.yaml` 版本化的数据发布。
- `assets.factor_database`、`assets.factor_index`、`assets.factor_dir`。
- `assets.strategy_index`、`assets.strategy_dir` 和 `assets.factor_tool`。
- AI 的 `base_url`、`api_key` 和 `model` 配置。

写入：

- `storage.factor_backtest_database`：批次、状态和标量指标。
- `cache.dir`：可重建的本地字段/回测缓存。
- 按存储格式配置的实验结果文件或可选结果后端。
- 日志和进程 PID 文件。

MarketData 输入只读；缓存和日志不能作为研究数据源。

## 10. 异常处理

| 异常 | 处理方式 |
|---|---|
| 配置缺失或格式错误 | 启动失败并显示配置项名称 |
| 清单、数据版本或文件哈希不匹配 | 启动失败，不提供可用服务 |
| 请求字段或参数无效 | Schema / 业务校验拒绝请求 |
| 回测队列满 | HTTP `429`，调用方稍后重试 |
| Manager 已关闭 | HTTP `503` |
| 任务 ID、批次 ID 不存在 | HTTP `404` |
| Provider / 行情数据缺失 | 返回明确错误，不用未声明来源的数据静默补齐 |
| AI Provider 不可用或输出无效 | AI 请求失败或以结构化信息说明降级；普通回测不依赖 AI |

---

## 11. 性能要求

- 数据量：随外部 MarketData 发布变化，仓库未定义固定上限。
- 并发：默认 2 个 Worker 线程，额外排队 8 个任务；可用配置调整。
- HTTP Uvicorn Worker：正式入口固定为 1。
- 响应时间、内存和 CPU：仓库未定义 SLA；按发布数据及目标部署环境测量。

---

## 12. 风险

- Python 策略代码与服务同进程执行；当前缺少资源隔离。
- 任务状态跨进程不共享，不能直接水平扩容。
- MarketData 的历史覆盖和字段可得时点需要研究人员核对，NA 不能自行解释成业务状态。
- API 未实现认证授权，部署网络边界必须受控。
