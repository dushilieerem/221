# 技术决策

本目录保存只影响 ResearchEngine 模块边界、执行管线、数据访问或公开 API 的长期技术决策（ADR）。

项目级、跨模块决策在 SVQuant 的 `docs/技术决策/`，不在本仓库复制。

## 当前决策状态

| 状态 | 决策 | 是否进入当前架构基线 |
|---|---|---|
| 已接受 | ADR-018、019、020、022 | 是，分别约束区间语义、并发、批量存储和共享运行时。 |
| 当前接口/执行约束 | ADR-021、024、025 | 是；异步任务、`/api` 前缀和统一执行原则已落地，旧 Executor 内容仅作历史记录。 |
| 与项目级决策共同生效 | ADR-023、SVQuant ADR-028/029 | 是；单一 `app.*` 命名空间、BacktestEngine 四引擎和 services/models/database 分层是当前基线。 |
| 提议/后续演进 | ADR-012、013、015、026 | 否；只能作为后续需求输入，不覆盖当前架构的已实施描述。 |

## 维护规则

- ADR 通过后，同步更新 `../架构与技术/系统架构.md`、对应功能包和模块设计。
- 旧版展开稿见 `../归档/架构历史/researchengine_architecture.md`，不作为当前实现基线。
- 跨仓库决策引用 SVQuant 文档，不复制全文。
