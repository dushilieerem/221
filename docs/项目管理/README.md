# 项目管理

本目录保存 ResearchEngine 模块级交付追踪：当前实现状态和阶段汇报。

## 目录

| 目录 | 用途 |
|---|---|
| [模块状态/](模块状态/) | 当前实现状态、已交付能力和缺口 |
| [阶段汇报/](阶段汇报/) | 阶段进展、质量结论和交付汇报 |

功能包的验收证据和交付记录在对应 [`../功能包/FEAT-*/`](../功能包/) 内维护；本目录只保存模块级管理事实。

## 规则

- 状态变化同时更新对应功能包 README 和本目录。
- 会议或实现产生的新结论，在一个工作周期内回写。
- 项目级计划、风险和发布记录在 SVQuant 项目管理文档，不在本仓库复制。
